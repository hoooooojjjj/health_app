## 👤 1. 사용자 신체 프로필 & 제약 조건 (Constraints)

> [!CAUTION]
> 본 애플리케이션의 핵심 철학은 **"안 아픈 게 가장 빠른 길"**이며, 수학적/객관적 데이터 기반의 안전한 증량을 지향합니다.

- **기본 체격**: 키 183cm (긴 리치/가동범위), 몸무게 70kg (목표: 근비대 및 프레임 확장)
- **요추 디스크 요주의**: 척추의 수직 압박(Compression) 및 과신전(Extension)을 유발하는 종목 주의. 복압 브레이싱(Bracing) 상시 유도.
- **왼쪽 어깨 불균형**: 가동성(Mobility) 부족으로 인한 찝힘 현상 방지 필요.
- **긴 팔(Reach) 특성**: 머신 운동 시 최대 이완이 어려울 수 있어 자유도가 높은 덤벨 종목 위주로 정렬.

## 🗓️ 2. 운동 프로그램 아키텍처 (3분할 2회전 시스템)

루틴은 1회전(너비/대근육 위주)과 2회전(두께/팔/소근육 위주)으로 나누어 매주 교차하여 로드합니다.

```
[주간 루틴 사이클]
Day 1,2,3 (1회전: 대근육 & 너비)  ➡️  Day 4,5,6 (2회전: 소근육 선행 & 두께/후면)
```

### 💡 부위별 세부 로직 및 보정 알고리즘

1. **가슴 & 삼두 (Push)**
   - 덤벨 프레스 시 요추 보호를 위해 필요할 경우 벤치 위에 발을 올리는 '허리 보호 모드' 적용.
   - **2회전 전략**: 팔 근육량 증대를 위해 삼두 운동을 가슴보다 먼저 배치하여 고립 피로도 극대화.
2. **등 & 이두 (Pull)**
   - **어깨 충돌 방지 궤적**: `수평(Row) ➡️ 대각선(High Row) ➡️ 수직(Lat Pulldown)` 순서로 점진적으로 가동 범위를 확장.
   - 긴 리치를 고려해 티바로우 대신 자유도가 높은 인클라인 덤벨 로우 우선 배치.
3. **어깨 & 하체 (Shoulder & Legs)**
   - 사레레 머신은 전완 개입을 차단하는 팔꿈치 패드형 모델로 유도.
   - 하단 텐션 유지를 위해 골반 높이의 케이블 레터럴 레이즈 활용.
   - 후면 볼륨 확장을 위해 2회전에서 리어델트 머신과 페이스풀 비중을 확대.

## 📈 3. 트레이닝 알고리즘 (Training Algorithm)

### 1) 증량 판정 로직: "2-2 법칙"

- **데이터 필드**: `Target_Reps`(목표 개수), `Clean_Reps`(완벽 자세 개수), `Dirty_Reps`(자세 무너진 개수)
- **알고리즘**:
  1. `Clean_Reps`가 `Target_Reps`보다 **2회 이상** 많은가?
  2. 위 조건이 **2세션 연속**(`Success_Streak == 2`) 충족되었는가?
  3. **결과**: 다음 세션에서 **무게 증량** 자동 제안.
- **자세 판정**: `Dirty_Reps`는 기록은 유지하되 증량 조건 계산 시에는 0점으로 처리하여 '가짜 힘' 배제.

### 2) 세트 구성 및 과부하 분석

- **본 세트 무게 기준**: 완벽한 자세와 가동범위로 **6~8회** 겨우 수행 가능한 중량을 본 세트 중량으로 설정.

| 구분                  | 목표 및 강도 설정                                                      |
| :-------------------- | :--------------------------------------------------------------------- |
| **웜업 세트 (1세트)** | 본 무게의 40~50% 중량으로 15~20회 실시 (관절 윤활유 역할, 세트 미포함) |
| **1세트 (최대 중량)** | 가장 컨디션이 좋을 때 6~8회 타겟 (근성장 신호 자극)                    |
| **2세트 (최대 중량)** | 1세트와 동일 중량으로 6~7회 수행                                       |
| **3세트 (볼륨 확보)** | 무게 5~10% 하향 조정한 후 8~10회 수행                                  |
| **4세트 (마무리)**    | 3세트와 동일 무게로 타겟 부위 완전 피로 누적 후 종료                   |

- **신경계 적응기(Neural Adaptation Phase) 플래그**:
  - 증량 직후에는 일시적으로 `Clean_Reps`가 줄어 `Total Volume (무게 × 횟수)`이 일시 감소합니다.
  - 앱은 이를 경고가 아닌 **적응기**로 판단하고 사용자에게 격려 메시지를 출력하며, 이전의 최고 볼륨 스코어를 돌파할 때까지 해당 중량을 유지시킵니다.

## 📲 4. 앱의 핵심 기능 요구사항 (UI/UX)

1. **듀얼 카운터 데이터 입력**: 세트 완료 후 '완벽한 자세의 개수(Clean)'와 '치팅 포함 개수(Dirty)'를 각각 분리해 터치 입력할 수 있는 UI.
2. **세션별 루틴 스위칭**: 매주 1회전/2회전 구성으로 운동 루틴을 자동 분기 로드.
3. **스마트 타이머**: 소근육(30초~1분)과 대근육(1분 이상) 운동의 휴식 시간을 자동 분리 세팅.
4. **컨디션 기반 실시간 Re-balancing**: 운동 시작 전 허리/어깨의 통증 레벨을 진단하여 그날의 운동 순서나 랫풀다운 등을 루틴 후반부로 다이내믹 정렬.
